# Matching to sample (`matching_to_sample.py`)

A sample geometric shape is shown alone for **1 second**, then replaced by two choice shapes. The individual must touch the shape that matches the sample. Stimuli are drawn from `Training_Stimuli/Geometric_Shapes/`.

Input: touchscreen.

---

This is a reference implementation under `Examples/`, not a deployable app — see the [main README](../../README.md) for context. It's teaching material and a starting-point template for building new apps, self-contained with its own `Training_Stimuli/`/`SoundEffects/`.
