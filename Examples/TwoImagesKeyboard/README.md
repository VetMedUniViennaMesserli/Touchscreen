# Two images — keyboard (`two_images_keyboard_input.py`)

Identical to Two images but responds to key presses instead of touch. Press **A** to select the left image, **D** to select the right image. Compatible with the Raspberry Pi Pico W hardware button box (`Devices/Keyboard/`).

Input: keyboard (A / D).

---

This is a reference implementation under `Examples/`, not a deployable app — see the [main README](../../README.md) for context. It's teaching material and a starting-point template for building new apps, self-contained with its own `Training_Stimuli/`/`SoundEffects/`.
